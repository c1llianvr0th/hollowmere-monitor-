# hollowmere-monitor

A lightweight uptime and environmental monitoring utility
developed for the Hollowmere Data Vault.

The service monitors server racks, temperature fluctuations,
access events and system availability.

## Features

- Rack temperature monitoring
- Basic environmental alerts
- System heartbeat tracking
- Badge access event logging
- Automated nightly backups
- Configurable monitoring intervals

## Installation

Clone the repository:

git clone https://github.com/CillianVroth/hollowmere-monitor.git

Install dependencies:

pip install -r requirements.txt

## Usage

python monitor.py --config config.yaml
